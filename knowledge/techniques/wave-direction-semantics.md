# 衝撃の進む向きで力の意味を読ませる

## 何を伝えるか

衝撃の波・輪・圧の層は、形よりも**攻撃の向き（力の軸）に対してどちらへ進むか**で意味が読まれる。

| 進む向き（力の軸との関係） | 読まれ方 |
| --- | --- |
| 軸の前方へ、外へ開きながら進む（軸との内積が正） | 押し出す・打ち出す・力を相手へ伝える |
| 軸に直交する方向だけへ広がる（内積0） | 受け流す・逸らす・衝撃を逃がす（パリィ） |
| 外から中心・手元へ集まる（内積が負、または内向き） | 溜める・吸収する・引き込む |
| 軸の後方へ抜ける | 反動・押し返された |

押す技のつもりで、押す面に沿った平らな輪を広げると、内積0の方向だけへ進むため受け流しに見える。

## 作り方

- 先に技の意味（押す／逸らす／溜める）を決め、その向きに層の進行を合わせる。形の種類（輪・面・粒子）はその後に選ぶ。
- 押し出しを輪で表すなら、輪を平面にせず、内側ほど力の軸の前へ出した球面（椀）にして、前へ押し出しながら広げる。前面から外へ逃げる圧に見える。
- 受け流しは逆に、輪を接触面に沿わせて横へ流す。
- 一つの技の中で、進む向きの違う層（押す輪と横へ流れる塵など）を混ぜると意味がぶれる。補助の層も主役と同じ向きにそろえる。

## 確認

力の軸を横から見た向きで撮り、輪・波の各部が軸の前へ進んでいるか、横へだけ広がっているかを見る。正面からでは区別できない。
