# 継続の状態は記号でなく、同じ色の粒子の流れる向きで表す

## 何を伝えるか

継続の状態表示は長く出続け、他の効果と重なる。上向き・下向きの山形や穂のような**記号**は意味が強すぎ、表示の範囲も広くなる。記号を小さくしても、別の意味に読まれる（片腕の欠けた下向きの山形がチェックマークに見えた例）、何か分からない（穂が「食べ物？」）ことがある。

| 量 | 読まれ方 |
| --- | --- |
| 流れる向き | 上昇＝強化・活力、下降＝弱体・低下 |
| 色 | 状態の種類（同じ向きの状態どうしは色で分ける） |
| 粒の形・速さ | 補助の差（鋭い線で速い＝強い号令、丸い粒でゆっくり＝穏やかな鼓舞、穀粒＝食事） |
| 色の暗さ・密度・速さ | 同じ種類の強さ（強い弱体は通常の弱体より暗い別の色で、少し多く速く） |

## 作り方

- 身体の外縁の狭い円筒（身体の幅の半分ほどの半径）から出し、頭の上や足元へ大きく広げない。
- 弱体は針のような細い線（伸ばした粒）が下降する形が読みやすい。強化は同じ線を上昇させる。
- 粒子はゆっくり動かす。攻撃の演出と同じ速さで流すと、継続表示としては速すぎて落ち着かない（目安は身体の高さを数秒かけて進む程度）。速さだけを落とすと移動の範囲も縮むので、範囲は寿命で保ち（速さを 1/n にしたら寿命を n 倍）、見える粒の数は発生の頻度で保つ（頻度を 1/n）。線は速さで長さが決まるので、遅くしたぶん伸ばす倍率で長さを保つ。
- 同じ向きの状態は**色で棲み分ける**。数（二枚・三枚）や形の細部の差では区別できない。
- 付与（apply）の瞬間の効果は記号を使ってもよいが、継続（active）と色を合わせる。継続の色を変えたら付与も変える。

## 確認

同じ向きの状態を並べ、色だけで区別できるかを見る。他の効果と重ねて、継続表示が主張しすぎないかを見る。
