# 体内で生まれる力の溜めは、外から集めず内から漏れる光で表す

## 何を伝えるか

溜めの粒が外から内へ向かうと「周りから力を集めている」と読まれる。魔法の詠唱や気合のように、外の力を集める技にはこれが合う。体内で力を生み出す技（魔物の喉の奥で炎を作るブレスなど）に外からの収束を使うと、出どころが違って見える。

| 力の出どころ | 溜めの表現 |
| --- | --- |
| 周りから集める（詠唱・気合・狙い） | 外から内へ向かう粒・締まる輪 |
| 体内で生まれる（ブレス・内なる力） | 内の核が強まり、口や隙間から光の筋が漏れ、だんだん太く明るくなる |
| 自然に治る力（自己再生） | 主張しすぎない。少ない粒と小さな光だけ |

## 作り方

- 漏れる光の筋は、出口から外へ遅い速さで出した粒を後ろへ引き伸ばして作り、根元を出口に残す。時間とともに数と明るさを増やす。
- 出口のまわりを淡い光でぼんやり照らす。漏れる炎・煙を少し添える。

## 確認

溜めの間、力が外から来るのか内から来るのかが一目で分かるかを見る。
