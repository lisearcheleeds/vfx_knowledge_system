# 知識基盤の初期確認

これはエンジン上のVFX Benchmarkではなく、知識の再利用・拡張と構造検証の確認項目である。

| 確認 | 操作・期待する結果 |
| --- | --- |
| Techniqueの共有 | 2つのRecipeがmesh-coreとbillboardを参照し、両方が逆参照に現れる |
| 同一役割の複数候補 | 各Recipeのcore役割に2候補があり、候補の存在だけで両方を採用しない |
| 新規知識の追加 | 未知の名前のノードと関係をMarkdownで追加し、索引・検索・逆参照に現れる |
| 必須依存の解決 | 採用したRecipeとTechniqueから、無条件の必須構成だけを取得する |
| 条件の未判定 | whenを持つ必須依存は、判断記録がなければ未判定になる |
| Adapterの選択 | 複数エンジンのAdapter対応リンクを探索しても、依存として採用しない |
| 不正入力 | 重複ID、存在しない参照先、条件付きも含む必須循環を拒否する |

自動確認は `tests/test_knowledge.py` で行う。追加・不正入力・Adapter・実行記録のテスト用データはリポジトリ内の一時コピーだけに作り、正本や実際のEvidenceとして登録しない。

構造確認の結果は[状態記録](../docs/STATUS.md)へ残す。VFX制作・撮影・修正・性能の証拠とは分ける。
