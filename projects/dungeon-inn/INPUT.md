# DungeonInn：受領した制作対象とゲーム側の契約

ユーザーが会話に貼り付けた一覧を記録する。出所として示されたのは `DungeonInn/Client/Assets/DungeonInn/Runtime/Scripts/Master/HardcodedMasterRepository.cs:4021`。外部プロジェクトのファイルは直接読んでいない。マスタ値は受領内容として扱い、演出の提案値とは分ける。

マスタ件数はスキル15件、状態効果14件、消費アイテム16件、武器の戦闘定義16種類。個別品目16件とActorEffectIdの対応も、追加で受領した。

## 設計上の扱い

共通知識にはゲーム契約を固定しない。このフォルダの対応表にゲーム契約・採用レシピ・個別調整を記録する。ナレッジIDは参照用であり、実行時のEffectIdではない。EffectIdと最終的な共用アセット範囲は比較後に決める。
