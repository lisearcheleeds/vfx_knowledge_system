# 最高品質の基準版からゲーム用版への変換（71件）

## 対象

2026-10-10。DungeonInn `art/game-vfx`（ステージ済み・未コミット）。基準版は `Client/Assets/DungeonInn/Editor/EffectBaselines/{NormalAttack, Skill}`、ゲーム用版は `Runtime/Content/Effect/Effects/`（通常攻撃は `<EffectId>_<名前>`、スキルは `Skill/<名前>`）。計画と結果の正本は DungeonInn `docs/design/effect/game-effect-plan.md`。制作はClaude Code。外観の再承認（B5）はユーザー待ち。

## 方法

- 予算（暫定）: 同時に既定100個・最低保証50個（PC）。区分 小（2系・12粒）／中（3系・24粒）／大（5系・64粒）。
- 共有素材: 粒子用の GameParticle（マスク1回）と、帯用の GameBand（ノイズ1回）の2 Shader、素材4つ（アトラス・帯・地面・尾）。
- 生成スクリプトで、基準版の素材の値から細い帯メッシュと時間の曲線を作り、粒子の層は共有アトラスへ付け替え、演出ごとの指示（削除・数・まとめ方）だけを手で与えた。
- 基準版と同じ視点・時刻の5コマを上下に並べて比べた。

## 結果

- 71件すべてが共有素材だけを使い、Editorの資産を参照しない。最大は火炎の息（5系・粒の上限68）。
- 予算超過は4件（大鎌・拳圧の系の数、地響きの溜めの系の数、火炎の息の粒）。いずれも、まとめると見た目が崩れる層（回る窓・時刻が違う）を分けたまま残したため。

## 比較で見つけて直したこと

| 症状 | 原因 | 直し方 |
| --- | --- | --- |
| 帯の模様が平板、輪の崩れが片側に偏る | 法線に詰めたノイズの縮尺が正規化されていた | UVの整数部に詰める |
| 星・輪のタイルが丸い光になる | startFrame は比 | (コマ＋0.5)／16 |
| 矢の本体・牙が薄い | メッシュ粒子にタイルが効かない、片面描画 | UVをタイルへ焼き直し、両面描画 |
| 投射体の尾が何十メートル | トレイルの寿命は比 | 秒／本体の寿命 |
| 広がる輪が太い塊になる | 全体の拡大で厚みも太る | 基準の半径で作り比で動かす（LW-C8） |
| 広がる輪が基準版より長く残る | 基準版は外周を越えた所で切れて消える | 越える時刻で消す |
| 閉じた輪に放射状の線 | 端の柔らかさ0が端の頂点の不透明度を0にしていた | 0は端を消さない |
| 三日月が淡いベージュ | 基準版は色の深さを時刻ごとの厚みで測る | 細る途中の厚みで色を焼く |
| 粒が出ない演出がある | 発生率が曲線のとき上限の見積もりが1倍で数えていた | 曲線の最大で数える |

## 共通知識へ還元したこと

- `rendering/lightweight-vfx-catalog` に LW-C7（形が不変の残像は剛体メッシュ）、LW-C8（厚みを保つ輪）、LW-E6（色の差が消える焼き込みを避ける）、LW-F6〜F8（まとめ方と、まとめてはいけない条件）を追加し、LW-F5 に数え方を足した。
- `adapter/unity-urp-game-particle-conversion` に Unity の粒子の事実と回避をまとめた。

## 続き: 再生を 2 段にし、多用する演出を焼き込みのインスタンス描画にした（2026-10-10）

- 実測で、ParticleSystem は系ごとの固定費が支配的と分かり、ユーザー判断で再生を 2 段（標準＝焼き込み・インスタンス描画、豪華＝ParticleSystem）にした。DungeonInn task_0371 で 65 件を焼いた。正本は DungeonInn `docs/design/effect/effect-rendering-design.md`、根拠は `docs/proposals/effect-playback-two-tier.md`。
- 焼き込みの再現で直したこと: 時刻ごとの再模擬で Loop の発生位置が飛ぶ（順進めに）、縦のビルボードの向きと回転の軸（カメラの位置・板の面内）、色の線形変換。寿命の端の 1 記録フレームの差は許容とした。
- Batches が増えた（46 → 201）点は、焼いたテクスチャごとに素材が分かれたため。ユーザー判断で、焼いたデータを Shader ごとに 1 枚のアトラスへ詰め、粒子の層を共通の四角のメッシュでまとめ、記録を絞る方針にした（DungeonInn task_0374）。

### 共通知識へ還元したこと（続き）

- カタログ: 費用の見方に「Batches の数だけで比べない」、LW-D8（焼き込みのインスタンス描画）・D9（アトラス、配列テクスチャの無駄）・D10（共通の四角のメッシュ）・E7（記録を絞る）。
- アダプター: 時刻ごとの再模擬の罠、縦のビルボードの向きと回転、系ごとの固定費、色の線形変換。
