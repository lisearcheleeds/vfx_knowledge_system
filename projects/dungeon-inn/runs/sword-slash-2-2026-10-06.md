## 既存の手法（前任版・旧ナレッジ）と違えたところ

| 既存 | 今回 | 理由・結果 |
| --- | --- | --- |
| 共有の円SDFテクスチャで内側を抜く（VfxShapeAlphaの内側SDFモード） | 弧帯UV上の解析式で厚みを関数として持つ | 非対称・尖り・短縮後の再尖りを連続に制御できた。テクスチャ解像度に縛られず、縁は `fwidth` で揃う |
| 三日月の厚みは参照の四段階に合わせる（形の対称性は特に決めない） | 厚みの最大を振り終わり寄りに置いた非対称 | 止まった絵でも振った方向が読める |
| 消失の最後は細い外縁が残って消える | 細い外縁を明るいまま振り終わりの先端へ縮めて消す | 暗くして消すと茶色の弧になった。縮める方が方向が残る |
| 立上りは0.075秒（曲線は特に決めない） | 尺は保ち、前半で大きく上げる曲線 | 半透明の濁り（オリーブ色・灰色）の時間が短くなった |
| 主面のalphaを保ち、端だけ透明に | 同じ考えに加え、外縁の外側に外光を加算で置き、前乗算で明部の一部を加算 | Bloomなしでも刃の熱が出る。ただし明るい背景では淡くなる |
| 共通Shader（VfxShapeAlpha）に機能を足していく | 基準版専用の新Shaderを作った（ユーザー判断で一時許可） | 前任の設計に引っ張られずに作れた。B工程で統合を判断 |
| 補助の後流・流線の層（SoftWake / FlowLines） | 補助の帯を作ったが削除。模様は主役の中の筋で表す | 暗い補助帯は黒背景で泥色の爪痕・二重線に見えた |
| 評価は45度俯瞰の通常の画角 | Previewの描画を任意の俯角・方位・時刻で書き出し、一覧画像で毎回評価。振り面の真上からも撮る | 真上で「深い三日月ではなく幅の揃った帯」と分かった。45度だけでは気付けなかった |
| 指摘の一部を直す | 自分で4回、全体を通しで見て直した（色→厚み→補助層→最後の段階→立上り） | 各回で弱点を書き出し、全体の再生に戻った |

## 失敗と、その原因（知識の不足か、工程の問題か）

- 色が茶色く沈んだ: 暗い橙を高いalphaで黒背景に置いたため（知識の不足。技法ノートへ追記した）。
- 帯が細く見えた: 内縁側の透明化が早すぎた（帯の75%から透明）・抜きが前半で急だった（知識の不足）。
- 火花の誤読: 「金属の手応え」を斬撃の残像の中に入れた（採用の誤り。残像は判定後の空間、火花は命中点の演出で、所有が違う）。
- 補助の風圧の失敗: 主役より暗い帯を重ねた（採用の誤り）。

## 未解決・次

1. 消失の時間カーブ（抜き・短縮・先端への縮みの各カーブ）。0.1秒単位の調整。
2. 明るい背景で淡くなる点（加算の比率、外縁の暗い縁取りの検討）。
3. 45度俯瞰で厚みが潰れる点（振り面の傾き）。
4. 先端の閃きが火花と同じ誤読を生むかの確認。
5. 短剣・大剣への展開は、剣の消失カーブが決まってから。
6. ゲーム用削減・接続・性能（B工程）。
