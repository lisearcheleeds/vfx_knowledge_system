## 制作中の観察（ユーザー評価前・制作者の観察）

| 観察 | 対処 |
| --- | --- |
| 片腕だけ欠けた下向きの山形は、小さく表示するとチェックマーク（肯定の記号）に見えた | 左右対称の下向きの山形に、両腕の外側の同じ位置の欠けにした |
| 炎の形を描いた板（炎の舌）は、何枚あっても小さな三角の記号に見えた | 柔らかい丸を上への動きで引き伸ばした粒にした |
| 前方の扇の範囲を炎で埋めるのに、三回の一斉発生では一つの塊が前へ移動するだけだった | 一度の吐き出しのあいだ（約0.25秒）口から流し続けて止めた |
| UnityのLimit Velocity over Lifetimeの抵抗は既定で粒子の大きさに比例し、大きな炎がすぐ止まった | 大きさ・速さに比例しない抵抗（multiplyDragByParticleSize=false）にした |
| 煙のテクスチャ（SmokeSoft）は小さく表示すると歯車のような縁に見えた | 小さい砂ぼこり・煙は柔らかい丸にした |
| 地面の衝撃波の輪が太く不透明だと、地面に置いた板に見えた | 細く薄くし、模様の対比を上げて地面のうねりにした |
