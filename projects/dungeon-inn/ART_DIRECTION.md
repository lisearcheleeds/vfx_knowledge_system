# DungeonInn：この版で採用するVFX制作方針

[受領一覧](INPUT.md)に対する、VFXアーティストとしての制作主案。火球以外は既存ゲームの映像・カメラ・Materialを確認した結果ではない。火球の実行したPreviewは[制作記録](runs/fireball-2026-10-04.md)へ記載する。現段階で良い初稿を作るために、形・素材・時間・階層を具体的に決める。個々の構成は[演出カタログ](CATALOG.md)から参照する。

## 形で攻撃を読み分ける

| 分類 | 主役として採用する形 |
| --- | --- |
| 剣 | 細く鋭い90度の弧と短い後流 |
| 斧 | 終端が厚い120度の弧と遅れる刃重 |
| 大剣 | 長い外縁と幅広い110度の刃面 |
| 鎌・旋風斬 | 一周する連続した弧。鎌は細く、旋風は発動の解放を強く |
| 短剣・槍 | 攻撃軸の針と一点の圧縮 |
| 棒・拳・盾 | 接触の面、幅広い星、遅れる薄い圧力環 |
| 爪・牙 | 平行する短い切り線／内へ閉じる二点 |
| 矢・ボルト | ゲーム入力に従う実体と一本の短い尾 |
| 杖・ワンド | 丸い柔らかな核／小さく鋭い滴状核 |
| 火球 | 内部密度の炎塊、後方への侵食面、熱から煙への尾、一回の着弾膨張と冷却 |
| 火炎の息 | 実範囲に合う円錐殻と大きな炎舌の一回の解放 |

固定扇形の斬撃はメッシュの展開を主役にする。武器先端の実軌道に沿う部分だけ履歴帯を添える。粒子は火花・葉・破片・炎舌等の役割へ限定し、形状の曖昧な粒子雲で全ての攻撃を代用しない。

## この版の配色

以下はsRGBの色指定。Materialの線形色・HDR発光値への変換はAdapterで行う。

| 用途 | 主色 | 面と芯 |
| --- | --- | --- |
| 物理攻撃 | 象牙白 `#EAE0C8`、補助の青灰 | 細い明るい外縁と暗い後流 |
| 無属性魔法 | 淡青 `#86CCF0` | 青の面と小さな青白の芯 |
| 火炎 | 橙 `#F68732`、赤 `#B7482B` | 小さな淡黄の熱核と橙の大きな舌 |
| HP回復 | ミント `#67DDA0` | 柔らかな葉・滴と短い白芯 |
| MP回復 | 淡青 `#53BDF5` | 細い結晶と静かな周回 |
| 攻撃強化 | 暖金 `#F3BD63` | 上向きの形と小さな付与ピーク |
| 攻撃低下 | 紫 `#9361BC`、暗紫 `#4B345D` | 欠けた下降形と低明度の面 |
| 土の衝撃 | 土色 `#9B8164` | 白い接触芯と薄い粉塵 |

色に加え、HPは葉、MPは結晶、強化は上向き、弱体は欠けた下向きで読む。敵味方の識別色は未提供であり、この属性配色から陣営を推測しない。識別を追加する場合はゲーム側の意味とProfileへ対応付ける。

## 明度と時間の仕上げ

主役の色面、細い発光芯、暗い外縁を別に持つ。最初のピークは小さく高く、減衰は大きな侵食と色の変化で作る。全面の白い面にBloomだけを乗せる仕上げは採用しない。

予兆は中心へ集める、発動は外へ解放する、余韻は薄く裂いて消す。この運動方向を一貫させ、接触と無関係なタイミングに最も明るいピークを置かない。

Recipeの0.04秒ピーク、0.20秒減衰、粒子個数などは、初稿を制作するために選んだ値。受領したマスタの詠唱・予備動作・速度・状態期間とは別の値であり、実測値ではない。

## 寸法と範囲

Wは対象Actorの身体幅、Hは身長、Lは武器の可視長、Rはゲームが渡す実範囲。物理寸法はメートルを基準とし、Actor/武器の寸法は実アセットのBoundsから得る。比率の基準を接続時に一つへ統一する。

主役の範囲境界は実際のR・角度で作る。装飾の拡大環と固定の境界を別にし、見た目のScaleでゲームの範囲を変更しない。斬撃の運動面は実モーション、地面境界は実判定の面へ置く。

## 準備・発動・飛翔・命中・状態の所有

- 準備は使用者、飛翔は実投射体、接触は実命中点、状態は実対象に置く。
- cast-start/cast-progress、attack-active、launch、impact/hit-confirmed、effect-applied/refresh/removeは必要な意味上の入力。この名前のイベントが既存コードにあるとは断定しない。
- 詠唱進捗と実発動に同期し、中断から成功演出を出さない。
- 状態applyは状態ハンドラが一回だけ所有する。Skill104とActorEffect8等の参照は知識の共用であり、二つのEmitterを同時発生させる指示ではない。
- 号令・鼓舞は自分への強化。隣のActorへ広がるバフ波を出さない。
- 火炎の息は一回の瞬間範囲。継続ブレスや刻みダメージを新設しない。

## 長時間状態の品質

300秒の活力は、良い付与の一回と小さな識別記号に分ける。大きな常時地面環・煙・火花を5分間維持しない。10秒の回復も毎秒フル演出を再生せず、実回復刻みでは記号と小光点だけを脈動させる。

Actor一体につきHP・MP・攻撃強化・攻撃低下をそれぞれ一組にまとめる。元の状態を複数保持し、代表する形だけ集約する。ゲームのスタック・回復量・期限は変更しない。解除・再付与・複合状態の各機能の終端は実データへ追従する。

## 修正できる構成として保存する

共通Recipeの主案は `composes: required` で記録し、このプロジェクトは[BINDINGS.json](BINDINGS.json)で採用先と個別調整を指定する。ゲーム固有ID・範囲・速度・期間を共通Recipeへ固定しない。これは「ファイアボールは世界中で必ずメッシュ」という一般則ではなく、今回の具体的な制作案を選んだ結果である。比較用のcandidateは採用へ自動混入させない。

改訂時は主役の形・時間・素材・関係を変更し、revisionと索引を更新する。技法と素材を共有する。火球は射出・飛翔・着弾の専用Prefabを作成済みで、他の実行時EffectId、共用単位、Variantの境界は未確定。

## 火球の品質基準版からの改訂

ユーザー判断で、まず表示サイズ・負荷予算への削減を保留して品質を追求した。主輪郭を球Meshから内部密度へ変え、方向流れ、侵食、熱から煙への遷移を採用。制作値と93/100の主観評価は[制作記録](runs/fireball-2026-10-04.md)へ置く。FlameShell0〜3の矩形面は動画で目立つため未完成。ゲーム接続・内部構造・密集負荷は未確認。他Recipeに制約の保留を自動適用しない。
