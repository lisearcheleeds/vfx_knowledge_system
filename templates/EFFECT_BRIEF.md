# Effect Brief

制作段階をA（最高品質基準版）/B（ゲーム用アセット化）で明記する。Aの計画は[品質制作計画](QUALITY_BASELINE_PLAN.md)と[Aの工程表](../docs/QUALITY_BASELINE_WORKFLOW.md)を使う。

| 項目 | 内容 |
| --- | --- |
| 制作ID・Profile版・知識コミット・制作段階 | 未定 |
| 合成後の完成像・目指す体験 | 未定 |
| 意味・用途・ゲーム上の役割 | 未定 |
| 必要な視覚情報・形状・動き・時間 | 未定 |
| 入力・発生位置・方向・追従・イベント | 未定 |
| 美術・カメラ・背景・同時表示 | 未定 |
| 品質目標と表現上の意図 | 未定 |
| ゲーム用予算・制約 | Aでは品質の上限にしない。Bで扱う |
| 合格条件・検証方法 | 未定 |
| 完成条件・中断時の扱い | Aは人間による最高品質基準版の完成承認。作業都合で止めても未完成 |

## 全体設計を先に記録する

完成外観→全体の時間演出→表現上の役割分解を記録してから技法を選ぶ。既存素材・最低限の意味伝達・設定の成功を完成像の代わりにしない。

## 候補比較

役割ごとに候補ID・改訂、条件、採用/棄却、理由、素材・能力、弱点、根拠の種類を記録する。

## 不足・仮定

未取得の必須依存、未確認の条件、追加候補、確認方法を記録する。

## 発火時点と残像の確認

- 発火は動作前・動作中・判定後のどれか。何が既に完了しているか。
- 表示するのは現在の刃か、通過済みの空間か。保存名から意味を推測しない。
- 参照の全体比率、帯幅、外側弧、内側抜き、残す端、時系列。コマ配置と空間移動を分ける。
- 立上り秒数と消失開始時刻。直列/並列の要求。主色・面opacity・端の透明化。
