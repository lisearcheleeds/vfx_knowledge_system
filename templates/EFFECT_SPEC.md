# Effect Specification

制作段階A/Bを明記する。Aは[品質制作計画](QUALITY_BASELINE_PLAN.md)の完成像・時間表・役割表を先に作り、下の実装仕様へ対応付ける。

| 項目 | 内容 |
| --- | --- |
| Effect ID・仕様版・Brief・Profile版 | 未定 |
| 意図・成功条件 | 未定 |
| 入力とspawn/launch/impact/stop/complete | 未定 |
| 時間・距離・角度の単位 | 秒・メートル・度を基準に、変換を明記 |
| 座標空間・基準半径・前方/上方/法線 | 未定 |

## レイヤー

各レイヤーのID、役割、必須性、採用技法、形状、寸法、分布、追従、動き、開始・停止イベント、相対時間、素材、描画、能力要件を記録する。

## 評価と制作段階

Aは完成像に対する造形・時間・質感・光色・空間・合成を、通常速度の全体連続再生と層比較で評価する。費用による削減案をAの設計へ入れない。

Bは承認済みの完成実物を改めて因数分解し、維持する情報、削減・近似候補、ゲーム用の画角・サイズ・性能を[Bの工程表](../docs/GAME_ASSET_WORKFLOW.md)で扱う。

## Engine Implementation Plan

対象Adapter・改訂・実行環境、採用機能・設定、単位/座標/色/アルファ変換、作成・再生・停止・破棄・再利用、コンパイル・撮影・計測の手順を書く。

## 工程への対応

各表現上の役割に、実装する部品と確認する時刻・合成状態を対応付ける。部品名の一覧だけで役割分解を完了にしない。工程の到達結果は品質制作計画へ記録する。

## 未確認事項

実装不足、未対応能力、未選定素材、仮定、次の検証を残す。値を記入しただけで検証済みとしない。

## 時間と部分修正の維持一覧

形状の完成時点、発火イベント、フェードイン開始/終了、内部UV開始、輪郭消失開始/終了を同じ秒の原点で記録する。形、色、面の濃さ、立上り、内部流れ、消失方向、終端、補助層を分け、修正ごとに維持・変更理由を照合する。

曲線の中心/支点と振り始めの端点を区別する。SDFを使う場合は外形と内側境界の役割、支持面とBounds、色UVからの分離、一枚で成立する輪郭族を記録する。
