# Project Profile

すべて実際の条件へ置き換える。未定は未定のまま残す。[Aの最高品質基準版](../docs/QUALITY_BASELINE_WORKFLOW.md)ではコストを品質の上限にしない。小表示・同時数・性能予算等は[B](../docs/GAME_ASSET_WORKFLOW.md)で適用する。

| 項目 | 内容 |
| --- | --- |
| プロジェクト識別・Profile改訂 | 未定 |
| エンジン・版・Renderer・関連パッケージ | 未定 |
| 対象端末・OS・解像度・品質・目標FPS | 未定 |
| カメラの投影・距離・画角・移動範囲 | 未定 |
| 色・形・輪郭・密度・質感の美術基準 | 未定 |
| ゲーム上の予告・範囲・優先情報・敵味方 | 未定 |
| CPU/GPU・メモリ・透明面積・同時表示の予算 | Bで適用。Aの品質上限にしない |
| 命名・保存先・アセット・再利用規約 | 未定 |
| 編集範囲・操作ツール・レビュー権限 | 未定 |
| 撮影・計測手段と必須検証場面 | 未定 |
| 知識リポジトリ・固定コミット・スキーマ版 | 未定 |
| ローカル拡張・対象IDへのoverrides | 未定 |
| 単位・座標・スケール・色・アルファ変換 | 未定 |

## 利用可能な能力

能力名、対応条件、確認状態（未確認/出典確認/実行確認）、根拠を記録する。未確認を対応済みにしない。
