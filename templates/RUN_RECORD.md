# 制作・評価・修正の記録

| 項目 | 記録 |
| --- | --- |
| 制作ID・日時・担当・要求 | 未定 |
| 知識コミット・スキーマ版・ノードIDと改訂 | 未定 |
| Profile版・エンジン・Renderer・ツール・端末 | 未定 |
| Brief・仕様・候補の採用/棄却理由・仮定 | 未定 |
| アセット・設定・Seed・再生/撮影/計測手順 | 未定 |

## 反復記録

変更前の観察 → 原因仮説 → 変更内容 → 変更後の観察を分ける。反復上限と停止理由を残す。

## 実行結果と証拠

実行した場面、動画・画像・ログの所在、実際に測った値、測定条件を記録する。未実行/未測定ならそう記載し、値を補完しない。

## 判定・未解決事項

採用/条件付き採用/棄却/継続実験、満たした条件・未達条件、次の検証を残す。

## 知識更新候補

共有できる観察、仮説、結論、適用範囲、未検証範囲、対象ノードを記録する。プロジェクト固有の調整は共有へ一般化しない。
