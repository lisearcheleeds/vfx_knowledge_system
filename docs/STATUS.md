## 最初の制作ワークフロー

**Unityで制作→撮影→人間評価→修正→知識還元を実施。性能計測・ゲーム統合を含む全体の実証は未完了。** [火球の制作記録](../projects/dungeon-inn/runs/fireball-2026-10-04.md)が固定版・採用値・観察・評価の正本。

射出・飛翔・着弾の3専用PrefabをUnity 6000.3.14f1 / URP 17.3.0 / Windows Editor / DX12で制作した。主役を球Meshから内部密度へ変え、方向性のあるUV流れ、侵食、熱から煙への尾、着弾の個体差を加えた。明暗背景・複数視点・動画・Clear後の再生を確認した。完成画像・動画・nativeアセットは利用プロジェクトの固定コミットへリンクし、ここへ複製していない。

ユーザーは体積基準版を大幅改善と評価した。後続では主役への貢献が小さい外炎・Trail・煙・見えない火の粉を削除し、Coreを面上密度と8頂点の折り曲げ式ビルボードへ置換した。前後方向で明部が折り目をまたぐ比率を修正し、飛翔の見た目は完成品質と承認された。[変換例](../projects/dungeon-inn/runs/fireball-downscale-2026-10-04.md)が後続の採否・値・検証の正本。基準版の記録は制作履歴として保持する。

今回画像・動画を再生成せず、ライブPreviewの描画・時計・シーク・人間評価を記録した。最終飛翔はRenderer1・ParticleSystem0。基盤のcompile/Shaderと規約確認に成功。独立した内部構造レビュー、ゲーム時計・イベント・Pool・階層復元、遮蔽・密集時性能は未確認。構成の削減をGPU時間の測定へ換算しない。

共通知識は面上密度と方向UV流れ・折り曲げ式の2技法、変換Evidenceを追加し、Unity Adapterと火球Recipeを更新。制作フローを最高品質基準版→削減版の見た目承認→ゲーム統合/実機検証に整理した。固有のID・比率・数値・主観評価はプロジェクト記録へ分離する。
