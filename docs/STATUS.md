2. 立体火球、剣/刺突/打撃、食事の複合状態から試作する。仕様に沿った素材・Material・Adapterを用意する。
3. 明暗背景、視点、密集、発動・命中・中断・解除・再利用を撮影・評価・計測する。
4. 状態は再付与による期限更新、実回復刻み、複合状態の独立終了、カテゴリ集約を確認する。
5. 観察に基づいて少なくとも一度修正し、再評価する。共通の知見はEvidenceとノード更新へ、固有の調整はプロジェクト記録へ戻す。

この循環を実行できて初めて、対象条件で制作ワークフローを実証したと報告する。
