# 未確定事項・追加候補

## 未確定事項

最初に実証するエンジン、具体的な版、Renderer、操作・撮影・計測手段、利用プロジェクトのProfile、美術・性能合格条件、ライセンス、第三者素材の扱い、レビュー・Release権限は未確定。

別プロジェクトを調査する前にユーザーへ確認する。土台の構築に不要な項目は推測で埋めない。

## 未登録の概念

以下は実際のID参照先ではなく、制作に必要になったときに設計・登録する追加候補。

| 概念 | 整備・確認する内容 |
| --- | --- |
| 軌跡・履歴帯 | 追従・帯の向き・履歴・停止・UV・性能 |
| 火炎外周 | 核と分けた揺らぎ、素材、時間関係、明度 |
| 着弾フラッシュ・煙 | impact起点、法線、形状、減衰、停止 |
| メッシュ・形状マスク・ノイズ等のResource | 寸法・単位・チャンネル・色空間・生成・利用条件 |
| 合成・深度・歪み等のRendering | 必要能力、背景依存、ソート、フォールバック |
| エンジン別Adapter | 具体的な版・Renderer・機能差・操作・再現検証 |
| 斬撃・爆発・バリア | 投射体以外で分類・構成・評価の再利用を確かめる |

登録済みRecipeは核の候補比較とライフサイクルを示す初期設計案であり、これらの未登録部分を網羅した実装レシピではない。
